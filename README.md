# tresorerie-aria
Outil de gestion d'argent pour les aventuriers d'Aria.

Bonjour à tous les rôlistes !

MJ et développeur débutant, je vous présente mon premier "vrai gros projet". Il est né d'une envie simple : ne pas m'embêter et ne pas embêter mes joueurs avec la gestion "complexe" de la monnaie dans le JdR Aria. Pour éviter de surcharger les feuilles de perso avec des ratures, j'ai créé ce convertisseur et tracker de solde.

À noter : Cette application est conçue pour que chaque joueur possède la sienne. C'est leurs bourse personnelle, vous gérez votre propre argent en toute autonomie.

Les fonctionnalités :
Conversion automatique : Plus besoin de calculer de tête pour savoir combien valent 5 sceptres en ou orbes.

Stockage des soldes : Gardez une trace précise et permanente de leurs fortune.

Historique des transactions : Chaque mouvement d'argent est enregistré. Vous pouvez nommer vos transactions (ex: "Achat d'une dague") pour savoir exactement où sont passés vos deniers.

Format Mobile (PWA) : Le site est installable directement sur votre téléphone comme une application. Idéal pour l'avoir sous la main, directement à table !

Coulisses techniques :
C'est un projet fait pour le fun et pour continuer mon apprentissage. Je me suis bien entendu servi de l'IA comme outil pour le JavaScript et l'optimisation mobile.

Visuels : 
Le fond et l'icône ont été générés par IA. C'était une solution simple pour moi car je voulais éviter tout problème de droits d'auteur en utilisant des visuels officiels d'Aria, tout en proposant quelque chose de propre. 

Open Source & Libre : Le code est à vous ! Faites-en ce que vous voulez : améliorez-le (mon code est loin d'etre propre et optimal xD) ou adaptez-le à d'autres systèmes de jeu, je le partage tel quel sans aucun souci.
